# Клеточки

Три игры для телефона и компьютера: судоку, японские кроссворды и поиск слов. 130 судоку, 30 японских кроссвордов и 30 тем поиска слов; любой уровень доступен сразу.

Личная версия: https://ringova.com/play/ · витрина: https://ringova.com/projects/

В судоку есть пометки, двойной тап единственного кандидата, нейтральные верные цифры, красные неверные и объяснения ходов. Японские — от 5×5 до 20×20, с автокрестиками, отменой штриха, масштабом и перемещением. Поиск слов — 30 тем и поля от 6×6 до 12×12: сначала видно количество, подсказка раскрывает одно оставшееся слово; выделение пальцем, мышью, двумя касаниями или клавиатурой.

Исходники: dist/, общий игровой код для личного сайта и трёх отдельных Яндекс-профилей. Личный сайт без рекламы и тега Метрики, помощь без ограничений. В Яндексе есть SDK, обучение, добровольная реклама с наградой и счётчик 113771637. Настоящие SDK/реклама и отчёты проверяются в черновиках.

```sh
npm test
npm run dev
npm run build:yandex
```

Сохранение v4: kletochki-progress-v4. Прежние v1/v2/v3 сохраняются без перезаписи, данные последовательно переносятся. У каждой Яндекс-игры отдельный progress-v4; баланс и попытки вне истории отмены. Другие устройства и приватные окна имеют собственное сохранение.

Архивы build/yandex/kletochki-{sudoku|nonogram|wordsearch}-1.5.0.zip: по одному на отдельную игру.

Полный комплект публикации: `python3 scripts/build-yandex-upload-kit.py --requirements-checked YYYY-MM-DD` после подготовки свежих игровых ZIP и медиа. Он создаёт три папки с ответами по полям, файлами и локальную `START-HERE.html` с копированием текста. Размеры, форматы, контрольные суммы и соответствие версии проверяются до выдачи. Дата — фактическая сверка текущей формы Яндекса. Порядок и требования к среде: [выпуск Яндекса](docs/yandex-release.md#полный-комплект-загрузки).

Документация: [правила для агента](AGENTS.md), [архитектура](docs/architecture.md), [руководство](docs/guide.md), [выпуск сайта](docs/runbook.md), [выпуск Яндекса](docs/yandex-release.md), [аналитика](docs/analytics.md), [загрузка целей через API](docs/metrica-api.md), [изменения](CHANGELOG.md).

Видимые номера идут по порядку: базовые 1–5, средние 6–30, сложные 31–70, эксперты 71–130. Нумерация отделена от стабильных идентификаторов сохранения: старые партии и достижения продолжаются на тех же полях. Новые задачи из выпуска 1.4 имеют видимые номера 11–30, 41–70 и 81–130. Каталог подготовлен офлайн scripts/generate-sudoku-pack.mjs и проверен на уникальность и объясняющую проходимость.

Японские от 10×10 показываются целиком по умолчанию с числами. Увеличение добровольное; «Всё поле» возвращает обзор. Яндекс-профили не прокручивают страницу: в коротких окнах управление размещается сбоку; длинные списки уровней/слов прокручиваются внутри своих панелей. Проверка: scripts/browser-viewport-qa.mjs.

Судоку: «Заполнить всё» появляется только когда весь остаток поля состоит из согласованных одиночных пометок. Один явный клик завершает поле с волной цифр, одна отмена возвращает пометки. Это бесплатное действие ввода в обоих профилях; не расходует платную помощь. Проверка: scripts/browser-finish-qa.mjs, она входит в CI перед публикацией.
