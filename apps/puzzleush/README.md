# Клеточки

Три игры для телефона и компьютера: судоку, японские кроссворды и поиск слов. 130 судоку, 30 японских кроссвордов и 30 тем поиска слов; любой уровень доступен сразу.

Личная версия: https://ringova.com/play/ · витрина: https://ringova.com/projects/

В судоку есть пометки, двойной тап единственного кандидата, нейтральные верные цифры, красные неверные и объяснения ходов. Японские — от 5×5 до 20×20, с автокрестиками, отменой штриха, масштабом и перемещением. Поиск слов — 30 тем и поля от 6×6 до 12×12: сначала видно количество, подсказка раскрывает одно оставшееся слово; выделение пальцем, мышью, двумя касаниями или клавиатурой.

Исходники: dist/, общий игровой код для личного сайта и трёх отдельных Яндекс-профилей. Личный сайт без рекламы и тега Метрики, помощь без ограничений. В Яндексе есть SDK, обучение, добровольная реклама с наградой и счётчик 113771637. Настоящие SDK/реклама и отчёты проверяются в черновиках.

```sh
npm test
npm run dev
npm run build:yandex
```

Сохранение v4: kletochki-progress-v4. Прежние v1/v2/v3 сохраняются без перезаписи, данные последовательно переносятся. У каждой Яндекс-игры отдельный progress-v4; баланс и попытки вне истории отмены. Другие устройства и приватные окна имеют собственное сохранение.

Архивы build/yandex/kletochki-{sudoku|nonogram|wordsearch}-1.4.0.zip: по одному на отдельную игру.

Документация: [правила для агента](AGENTS.md), [архитектура](docs/architecture.md), [руководство](docs/guide.md), [выпуск сайта](docs/runbook.md), [выпуск Яндекса](docs/yandex-release.md), [аналитика](docs/analytics.md), [загрузка целей через API](docs/metrica-api.md), [изменения](CHANGELOG.md).

Новые судоку: средние 31–50, сложные 51–80, эксперты 81–130. Прежние 1–30 не изменились. Выбор сложности объединяет прежние и новые задачи; переход после победы идёт по сложности и пропускает уже пройденные. Каталог дополнительных задач подготовлен офлайн scripts/generate-sudoku-pack.mjs и проверяется на уникальность и объясняющую проходимость.
