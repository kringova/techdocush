# Клеточки

Судоку с объясняющими подсказками и японские кроссворды. По 30 уровней на игру, интерфейс для телефона и ПК.

Основной адрес: https://ringova.com/play/ · витрина: https://ringova.com/projects/

Исходники входят в `apps/puzzleush` репозитория techdocush. Само приложение — статические HTML/CSS/ES-модули из `dist/`, без зависимостей и сервера.

```sh
npm test
npm run dev
```

Прогресс хранится в браузере под ключом `kletochki-progress-v1`. Перезагрузка сохраняет его; другие устройства и приватные окна имеют отдельный прогресс.

Документация: [правила для агента](AGENTS.md), [архитектура](docs/architecture.md), [использование](docs/guide.md), [публикация](docs/runbook.md), [изменения](CHANGELOG.md).
