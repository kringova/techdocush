# Клеточки

Судоку с объясняющими подсказками и японские кроссворды. По 30 уровней на игру, интерфейс для телефона и ПК.

Все уровни доступны сразу. В судоку пять базовых задач и прямой выбор «Эксперта»; двойной клик/тап вписывает единственную пометку. В японских пять 5×5, затем 10×10, 15×15 и 20×20; есть автокрестики, масштаб и перемещение больших полей.

Основной адрес: https://ringova.com/play/ · витрина: https://ringova.com/projects/

Исходники входят в `apps/puzzleush` репозитория techdocush. Само приложение — статические HTML/CSS/ES-модули из `dist/`, без зависимостей и сервера.

```sh
npm test
npm run dev
```

Прогресс хранится в браузере под ключом `kletochki-progress-v2`. При обновлении данные переносятся по соответствию самих головоломок, исходный ключ `kletochki-progress-v1` остаётся неизменным. Перезагрузка сохраняет прогресс; другие устройства и приватные окна имеют отдельное сохранение.
