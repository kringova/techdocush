# Клеточки

Судоку с объясняющими подсказками и японские кроссворды. По 30 уровней на игру, интерфейс для телефона и ПК.

Все уровни доступны сразу. В судоку пять базовых задач и прямой выбор «Эксперта»; двойной клик/тап вписывает единственную пометку. В японских пять 5×5, затем 10×10, 15×15 и 20×20; есть автокрестики, масштаб и перемещение больших полей.

Основной адрес: https://ringova.com/play/ · витрина: https://ringova.com/projects/

Исходники входят в `apps/puzzleush` репозитория techdocush. Само приложение — статические HTML/CSS/ES-модули из `dist/`, без зависимостей и сервера.

```sh
npm test
npm run dev
npm run build:yandex
```

Прогресс хранится в браузере под ключом `kletochki-progress-v2`. При обновлении данные переносятся по соответствию самих головоломок, исходный ключ `kletochki-progress-v1` остаётся неизменным. Перезагрузка сохраняет прогресс; другие устройства и приватные окна имеют отдельное сохранение.

Документация: [правила для агента](AGENTS.md), [архитектура](docs/architecture.md), [использование](docs/guide.md), [публикация](docs/runbook.md), [изменения](CHANGELOG.md).

Верные цифры тёмные, неверные красные. Для Яндекса из тех же исходников собираются две отдельные игры: кандидаты и пакеты из трёх подсказок за рекламу, три разрешённые ошибки в судоку и восстановление после четвёртой. Личный сайт без рекламы и лимита ошибок. Онбординг Яндекса включает тренировку двойного тапа.

Архивы: `build/yandex/kletochki-{sudoku|nonogram}-1.2.2.zip`. Подготовка кабинета, медиа и реальная проверка SDK: [выпуск для Яндекса](docs/yandex-release.md).

Для игровых отчётов подготовлены [события Метрики](docs/analytics.md). Яндекс-сборки используют выбранный счётчик 113771637; личная игра тег не загружает. Цели настраиваются в кабинете Метрики. Полная запись партий не реализована.
