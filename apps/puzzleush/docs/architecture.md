# Архитектура

- `dist/engine/sudoku.js`: детерминированные уровни, MRV-поиск количества решений, кандидаты, логические шаги. Генератор сохраняет только уровни, проходимые поддерживаемыми приёмами.
- `dist/engine/nonogram.js` и `large-nonograms.js`: 30 оригинальных рисунков 5×5, 10×10, 15×15 и 20×20, подсказки линий, кеш вариантов, пересечение и точный поиск решений. Полное логическое восстановление каждого рисунка доказывает уникальность.
- `expert-sudoku.js`: десять зафиксированных экспертных задач, сгенерированных из случайных полных сеток. У каждой единственное решение, полный объясняющий путь и минимум три шага исключения кандидатов.
- `progress.js`: четыре группы сложности/размера и чистая миграция v1→v2 по сохранённым задачам. Исходный ключ v1 не удаляется и не перезаписывается; v2 использует отдельный ключ. Результаты исключённых лёгких задач остаются в исходной записи, их число видно в выборе уровней.
- `dist/app.js`: ввод, локальные снимки для отмены, диалоги объяснений, прогресс. Снимки отмены живут в памяти; состояние поля и достижения — в localStorage.
- Подсказка судоку возвращает доказуемое помещение или исключение. Интерфейс никогда не применяет помещение; исключение применяется отдельной кнопкой после объяснения.
- Снятие/замена числа сбрасывает накопленные логические исключения, поскольку их основания могли измениться. Ручные пометки не используются как доказательство.
- Двойной клик/тап распознаётся между перерисовками поля. Вписывается только единственная видимая допустимая пометка; заполненная клетка не очищается. Это явный ввод, объясняющая подсказка сама число не вписывает.
- Для японских один pointer-штрих вместе с автокрестиками составляет один отменяемый ход. Автокрестики ставятся только при совпадении всех чёрных клеток линии с рисунком. ПКМ использует крестик независимо от выбранного режима. В мобильном режиме есть отдельные режимы рисования и перемещения; прокрутка сохраняется после хода и отмены, подписи липкие.
- Схема сохранения v2, ключ `kletochki-progress-v2`; v1 остаётся резервной записью. Некорректная запись не перезаписывается. При ошибке quota UI сообщает о невозможности сохранения. Все уровни свободно выбираются, прогресс ничего не блокирует.
- Нет учётных записей, аналитики, серверных данных, платных зависимостей или скрытого обмена прогрессом.

`tests/engines.test.mjs` проверяет уникальность/проходимость всех уровней и выводы каждого логического шага. `scripts/browser-qa.mjs` проверяет полный пользовательский путь в изолированном браузерном профиле.
