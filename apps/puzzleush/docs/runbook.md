# Размещение

Игры находятся в `apps/puzzleush` репозитория techdocush. Путь в проде — `https://ringova.com/play/`. DNS, VPS, пароли и существующие приложения для этого размещения не меняются.

`build.sh` основного сайта запускает `node --test apps/puzzleush/tests/*.test.mjs` и `node apps/puzzleush/scripts/sync-to-site.mjs --site-directory .` перед Hugo/Astro. Генерируемая `static/play/` исключена из Git; исходники находятся в приложении.

Обычный push в main запускает `.github/workflows/pages.yaml` и публикует весь гибридный сайт на действующем GitHub Pages. Дождаться job success; затем получить `/play/release.json`, сверить `source_commit` с опубликованным SHA и hashes ресурсов, открыть обе игры в браузере. Корневые страницы, `/docs` и витрину `/projects/` проверить отдельно.

Для отката вернуть конкретное изменение обычным `git revert` и дождаться Pages-deploy. Не удалять браузерные ключи прогресса v1/v2/v3/v4. Текущая v2-подборка переносит только те старые задачи, которые действительно сохранились; v1 остаётся неизменной резервной записью. Будущая смена нумерации или рисунков требует новой явной миграции. Откат к старому коду не удаляет новое сохранение v2, но оно будет видно только в совместимой версии. Серверных пользовательских данных нет.

Результаты браузерного прогона сохраняются локально в `test-results/` (игнорируется Git). Для запуска нужны Playwright/Chromium из среды: `PLAYWRIGHT_MODULE` и `BROWSER_EXECUTABLE` задают их пути без изменения приложения.

С выпуска 1.2 корневой build.sh также собирает три конфигурации для Яндекс Игр и сохраняет ZIP в CI как артефакт `kletochki-yandex`. Это не меняет профиль личного `/play/`: SDK, реклама и лимит ошибок там выключены. Загрузка архива, реальная проверка SDK и модерация описаны в [runbook Яндекса](yandex-release.md).

Версия 1.3 добавляет поиск слов и сохранение v3. При выпуске/откате сохранять ключи v1/v2/v3: старое приложение читает свой ключ и не затрагивает новый. Проверить миграцию существующего v2-профиля, открытие всех трёх игр и отсутствие тега Метрики в личной игре.
