# Corio

`/play/corio/` — витрина двух игр в общей вселенной белого курильского бобтейла с голубыми глазами и коротким серым хвостом.

- `/boxes/`: 50 головоломок с коробками. Займи все коврики, затем доберись до двери. Пять первых уровней собраны вручную, ещё 45 построены детерминированными обратными перемещениями коробок; для каждого сохранён и проверен путь решения. Размеры внутри стен: 5×5, 6×6, 7×7, 8×8, 9×9, по десять уровней. Коробок от одной до четырёх. Стрелки/WASD, кнопки, свайп, Z или ↶ для отмены, R для перезапуска.
- `/shelves/`: прототип сортировки кошачьих вещей, три раскладки. Переносить можно крайний справа предмет на пустую полку или рядом с таким же. Есть нажатия, перетаскивание и отмена.

`dist/` — самостоятельная статика без внешних библиотек, рекламы, аккаунтов и аналитики. Локальные результаты сохраняются в браузере; недоступность хранилища не блокирует игру. Спрайт кота пока один, без полноценного цикла походки. Canvas и кэш фона рисуются с учётом Retina.

Исходная разработка, визуальный канон, полные промпты, генератор уровней и браузерные проверки находятся в проекте `yandex-games-factory`. Иллюстрации сделаны встроенным image_gen по выбранному направлению C. Публичные метаданные — `dist/assets/provenance.json`.

`build.sh` сначала собирает существующие головоломки в `/play/`, затем добавляет Corio. Синхронизация Corio не изменяет родительский каталог и другие игры. Тесты: `node --test apps/corio/tests/*.test.mjs`. Публикация идёт штатной сборкой ringova.com через GitHub Pages. На Яндекс Игры проект ещё не отправлялся.
