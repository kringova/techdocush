# Corio: прототипы механик

`https://ringova.com/play/corio/` — витрина девяти игр про одного белого курильского бобтейла с голубыми глазами и коротким серым хвостом.

| Маршрут | Механика | Содержание |
|---|---|---|
| `boxes/` | Коробки на коврики, затем к двери | 50 уровней |
| `shelves/` | Крайний предмет на пустую полку или к такому же | 5 раскладок |
| `tunnels/` | Повернуть трубы и соединить полки/гамаки | 5 уровней |
| `food/` | Отделить подходящее коту от неподходящей еды | 5 тарелок |
| `pet/` | Согласовать корм, воду, игру и отдых | 5 коротких вечеров |
| `grooming/` | Ткань, щётка, вода, кошачий шампунь, смыв, полотенце, передышка | 5 эпизодов |
| `litter/` | Найти пары одинаковых форм среди пустых ячеек | 5 лотков |
| `yarn/` | Перетаскивать клубки, убирая пересечения нитей | 5 головоломок |
| `search/` | Найти предметы по списку, с приближением и подсказкой | 5 поисков: комната, кухня, двор |

Все уровни открыты для оценки механик. В каждой игре два режима: без ограничений и с бюджетом действий; общие музыка/шумы и прямые ссылки на остальные игры. Web-профиль бесплатный, пополнение +5 помечено «тест»: настоящих покупок и рекламы нет. Перманентная покупка в будущем отдельная для каждой игры, цена из SDK-каталога. Яндекс-публикация, каталог и ссылки приложений ещё не настроены.

`dist/` — самостоятельная статика без внешних библиотек/аналитики. `mini/engine.mjs` хранит чистые правила и пять сценариев новых игр, `mini/app.mjs` — общие управление/сохранения/режимы, `mini/views.mjs` — разные игровые сцены. `series.mjs` — реестр маршрутов. Локальные сохранения не мешают игре, если хранилище недоступно. Один кот использует разные позы и состояния; новая графика остаётся кандидатом для оценки пользователя. Полного цикла походки нет. Тамагочи не ухудшает потребности офлайн. Груминг не обучает реальной стрижке когтей и не затрагивает голову/усы. Персонажи двора и большой сюжет поиска ещё не разработаны.

Основная разработка/канон/источники/браузерные проверки — в `yandex-games-factory`. Снимок копируется его `tools/sync-corio-to-site.mjs`. Общий микшер: калимба, колокольчики v2, клавиши, дождь, ветер — собственный синтез; мурчание v3 — запись Joseph SARDIN / BigSoundBank, CC0, одобрена пользователем. `assets/provenance.json` содержит происхождение и хеши. Фоны поиска — оригинальные рисунки в полном разрешении с прозрачными областями нажатия; `Mystery Manor` использован только как жанровый референс. Правила еды сверены по Cats Protection/ASPCA; ссылки есть в игре.

Проверка: `node --test apps/corio/tests/*.test.mjs`; полная сборка — `./build.sh` с Hugo 0.132.2. После сборки существующего `/play/` добавляется Corio: порядок синхронизации сохранять. `static/play/corio` и `public/` — генерируемые каталоги. Публикация через обычный push в main и GitHub Pages. Другие игры `/play/` сохранять.

Версия0.6: новые позы кота, нарисованные комната/кухня/двор/уголок ухода, атлас12продуктов, лоток с2–6парами разных форм и пустыми клетками. Отмена, пауза и перезапуск отменяют устаревшее скрытие пары. SVG clipPath обрезает каждый спрайт по точной области, не по условной равной сетке.
